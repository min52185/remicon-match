# 레미go 시연 매뉴얼

**세 사람이 각자 계정 하나씩 들고 따라 하는 설명서입니다.**
발표자가 아니어도, 이 문서만 보고 그대로 누르면 시연이 됩니다.

- 주소: <https://remicon-match-iota.vercel.app>
- 소요: 준비 15분 + 시연 **15분**
- 계정: **현장 1 · 공장 1 · 기사 1** (아래에서 직접 만듭니다)

| 표기 | 뜻 |
| --- | --- |
| 🟦 **현장** | 현장 담당자가 하는 일 |
| 🟨 **공장** | 레미콘사 담당자가 하는 일 |
| 🟩 **기사** | 운송기사가 하는 일 |
| ✅ | 이렇게 보이면 정상 |
| ⚠️ | 여기서 자주 막힙니다 |

> **시연은 오전 8시 ~ 오후 5시 사이에 하세요.**
> 레미콘 운송 8·5제가 들어가 있어서, 그 밖의 시간에는 "지금 갈 수 있는 공장이
> 없습니다" 가 뜹니다. **고장이 아니라 정상 동작**이지만 시연으로는 보여줄 것이
> 줄어듭니다.

# 0부 · 준비 (15분, 관객 없이)

## 0-1. 기기 나누기

| 사람 | 기기 | 역할 |
| --- | --- | --- |
| A | **노트북** (화면 공유) | 🟦 현장 |
| B | 휴대폰 또는 다른 노트북 | 🟨 공장 |
| C | 휴대폰 | 🟩 기사 |

> 휴대폰이 없으면 노트북 한 대에서 **일반 창 / 시크릿 창(Ctrl+Shift+N) / 다른 브라우저**
> 세 개로 나눠도 됩니다. 다만 기사는 휴대폰이어야 GPS 를 보여줄 수 있습니다.

## 0-2. 계정 만들기 — 세 사람이 각자

1. 주소로 들어가 **[시작하기]** 또는 오른쪽 위 로그인
2. **회원가입** 탭
3. 아래대로 채웁니다

| | 🟦 현장 | 🟨 공장 | 🟩 기사 |
| --- | --- | --- | --- |
| 이름 | 아무 이름 | 아무 이름 | 아무 이름 |
| 역할 | **현장** | **레미콘사** | **기사** |
| 이메일 | 각자 다르게 | 각자 다르게 | 각자 다르게 |
| 비밀번호 | 6자 이상 | 6자 이상 | 6자 이상 |

4. 가입하면 **회사 고르기** 화면이 나옵니다. 여기가 제일 중요합니다.

| 역할 | 반드시 이 회사 |
| --- | --- |
| 🟦 현장 | **한빛건설** |
| 🟨 공장 | **가온레미콘** |
| 🟩 기사 | **가온레미콘** |

> ⚠️ **공장과 기사는 반드시 같은 회사(가온레미콘)** 여야 합니다.
> 다르면 4부에서 기사에게 배송이 안 뜹니다. **여기서 가장 많이 틀립니다.**

## 0-3. 🟩 기사 — 차량 맡기 (먼저 해야 합니다)

1. 로그인하면 **내 배송** 화면
2. **내 차량** 칸 → **차량 고르기** 에서 **1호차** 선택
3. **[이 차량 맡기]**

✅ `배정됨` 으로 바뀌고 호차·차량번호가 보입니다.

> ⚠️ 이걸 안 하면 **3부에서 공장이 배차할 차가 없습니다.**

## 0-4. 🟩 기사 — 얼굴 사진 (선택이지만 권장)

1. 맨 위 **내 정보** → **[내 정보 고치기]**
2. 연락처를 적고 **[저장]**
3. **동의 체크박스**를 켭니다 ← 켜야 사진 버튼이 풀립니다
4. **[사진 찍기 · 고르기]** → 아무 사진이나

✅ 오른쪽 위가 `사진 등록됨` 으로 바뀝니다.
→ 5부에서 현장 화면에 이 사진이 뜹니다.

## 0-5. 🟨 공장 — 출하 현황 확인

**출하 현황** 화면에서 가온레미콘 동탄공장이 이런지 봅니다.

| 항목 | 값 |
| --- | --- |
| 출하 가능 물량 | **240m³** |
| 출하 가능 차량 | **8대** |

다르면 지난 시연 자국입니다. `supabase/reset-rehearsal.sql` 을 돌리세요.

## 0-6. 🟦 현장 — 마지막 점검

- 시계 옆 배속이 **×1** 인지 (5부에서 올립니다)
- 브라우저 확대 **125~150%**
- 알림·메신저 끄기
- 화면을 **맨 처음 화면(로고 클릭)** 으로

# 2부 · 현장 등록과 주문 — 4분

✅ 목록에 `시연 현장` 이 추가되고, 오른쪽 위 현장 고르기에도 뜹니다.

**할 말**

> 아직 없으니 지도를 직접 눌러도** 됩니다. 이 좌표 하나로 이동시간과 배분이
> 전부 계산됩니다."

> 💡 다음 단계부터는 오른쪽 위 현장 고르기를 **서천동 근린생활시설 신축현장** 으로

## 2-2. 🟦 사양 직접입력

**할 일**
1. 아래 탭 **주문**
2. **레미콘 사양** 칸에서 **굵은골재 최대치수** 를 **직접입력** 으로 바꿉니다
3. `15` 를 칩니다 → 아래 문구를 보여줍니다
4. `200` 을 칩니다 → 문구가 바뀌고 **맨 아래 주문 버튼이 잠깁니다**
5. `25` 로 되돌립니다

| 입력 | 화면에 뜨는 것 |
| --- | --- |
| `15` | 🟠 표에 없는 조합 (15-24-150) — 공장 협의 필요 |
| `200` | 🔴 굵은골재 최대치수를 5~80mm 사이 정수로 입력하세요 |
| `25` | 🟢 KS F 4009 표준 조합 |

**할 말**
> "KS 표에 없는 조합도 협의로 만듭니다. 그래서 **막지 않고 알리기만** 합니다.
> 대신 200mm 처럼 말이 안 되는 값은 막습니다. 막는 것과 알리는 것을 나눴습니다."

## 2-3. 🟦 8·5제 경고

> 타설 종료가 오후 5시를 60분 넘깁니다. 8·5제에서는 기사가 퇴근하는 시각이라
> 타설이 끊길 수 있습니다. 물량을 줄이거나 시작을 앞당기세요.

**할 말**
> "레미콘 기사는 **오전 8시에 상차해서 오후 5시에 하차**하는 8·5제를 따릅니다.
> 점심 1시간을 빼면 하루 8시간입니다. 그런데 현장은 양생 때문에 타설을 중간에
> 끊을 수가 없습니다. 5시가 넘어가면 기사가 퇴근하면서 타설이 끊깁니다.
