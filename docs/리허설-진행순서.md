# 리허설 진행 순서

**손이 움직이는 순서 그대로** 적었습니다. 기존 [시연-시나리오.md](시연-시나리오.md)가
장면 단위라면, 이 문서는 "지금 어느 창에서 무엇을 누르고 뭐라고 말하는지"입니다.

- **발표 전** 5분 — 관객 없이 준비
- **본편** 약 10분 — 1막~10막

| 표기 | 뜻 |
| --- | --- |
| **[노트북]** | 화면 공유하는 기기 · 현장 계정 |
| **[폰A]** | 레미콘사 계정 |
| **[폰B]** | 기사 계정 |
| 🗣 | 말할 것 |
| ✅ | 이렇게 되면 정상 |

# 발표 전 (5분, 관객 없이)

### 1. 창 3개 열고 로그인

| 창 | 계정 | 열어 둘 화면 |
| --- | --- | --- |
| **[노트북]** | 현장 | `/` (랜딩) |
| **[폰A]** | 레미콘사 | 주문 관리 |
| **[폰B]** | 기사 | 내 배송 |

> 휴대폰이 없으면 노트북의 시크릿 창·다른 브라우저로 대신합니다.

### 2. **[폰B]** 차량 맡기

**내 차량** → 차량 고르기에서 **1호차** → **이 차량 맡기**

✅ `배정됨` 으로 바뀌고 호차·차량번호가 보입니다.

> 이걸 안 하면 5막에서 배차할 차가 없습니다. **가장 자주 빠뜨리는 단계입니다.**

### 3. **[폰B]** 얼굴 사진 확인

**내 정보** 오른쪽에 `사진 등록됨` 이 있으면 넘어갑니다.
없으면 **내 정보 고치기** → 동의 체크 → **사진 찍기**.

> 7막에서 현장 화면에 이 사진이 뜹니다.

### 4. **[폰A]** 출하 현황 확인

**출하 현황** — 가온레미콘 동탄공장이 `출하 가능 물량 240m³` `차량 8대` 인지.

> 다르면 리허설 자국이 남은 것입니다. `supabase/reset-rehearsal.sql` 을 돌리세요.

### 5. **[노트북]** 마지막 점검

- 시연 배속이 **×1** 인지 (5막에서 올립니다)
- 브라우저 확대 **125~150%** (뒷자리에서 보이게)
- 알림·메신저 끄기
- 화면을 **랜딩(`/`)** 으로 돌려놓기

## 1막 · 문제 제기 — 30초

**[노트북]** 랜딩 `/`

🗣 "레미콘은 비비기 시작하면 90분 안에 타설을 끝내야 합니다. 외기 25도 이상일 때 기준입니다.
앞차와 뒷차 사이가 벌어지면 먼저 친 콘크리트가 굳어버립니다. **콜드조인트**입니다.
구조체 강도가 직접 떨어지고, 한 번 생기면 되돌릴 수 없습니다."

🗣 "지금 현장은 이걸 전화로 관리합니다. 여러 공장에 일일이 전화해서 물량을 묻고 순서를 조율합니다.
저희는 이걸 화면 하나로 옮겼습니다."

**조작** 스크롤 → `01 주문 → 02 배분 → 03 추적 → 04 연속 타설` 카드

## 2막 · 주문 — 조건에 맞는 공장만 남는다 — 1분

**[노트북]** 아래 탭 **주문**

**조작**
1. 사양 기본값 확인 — 보통 / 25mm / 24MPa / 슬럼프 150mm
2. 총 물량 `60`, 펌프 속도 `40`
3. 아래 공장 목록을 위에서 아래로 훑습니다

🗣 "사양을 고르면 **만들 수 있는 공장만** 남습니다. KS F 4009 표를 그대로 넣었습니다.
그리고 제한시간 안에 도착할 수 있는지도 같이 봅니다."

**짚어줄 세 가지**

| 공장 | 화면 | 말할 것 |
| --- | --- | --- |
| 다온레미콘 수원 | 빨강 · 출하 여력 없음 | "차량이 전부 나가 있습니다" |
| 새봄레미콘 화성 | 빨강 · 출하 중지 | "설비 점검 중입니다" |
| 하늘레미콘 안성 | 빨강 · 시간 초과 | "99분 거리라 90분 제한을 못 맞춥니다" |

🗣 "빨간 건 누를 수 없습니다. 전화해서 확인할 필요가 없습니다."

> **시간이 남으면** 굵은골재를 `직접입력`으로 바꿔 `15` 를 쳐 보세요.
> 🗣 "표에 없는 조합도 협의로 만듭니다. 막지 않고 '협의 필요'라고만 알립니다.
> 대신 `200mm` 처럼 말이 안 되는 값은 막습니다."

## 3막 · AI 배분 — 2분 ★ 가장 중요

**[노트북]** 탭 **AI 배분**

**조작**
1. **「지시서 6장 A~G 예시로 계산」** 체크
2. **AI 배분 계산하기**

🗣 "300㎥를 6분마다 한 대씩 끊김없이 받아야 합니다. 50대가 필요합니다.
주변에 공장이 7곳 있는데 한 곳이 다 대지 못합니다."

**결과표를 가리키며**

| 공장 | 이동 | 추천 |
| --- | --- | --- |
| A | 15분 | 5대 |
| B | 20분 | 4대 |
| C | 25분 | 10대 |
| D | 30분 | 5대 |
| E | 35분 | **12대** |
| F | 45분 | **14대** |
| G | 60분 | **0대 — 제외** |

🗣 "G공장은 60분 거리인데 허용 이동시간이 50분이라 아예 뺐습니다.
중요한 건 **E와 F**입니다. 먼 공장인데 **처음부터 섞어 씁니다.**"

**조작** 아래 「가까운 공장부터 채우면 어떻게 되나」 칸을 가리킵니다

🗣 "가까운 A·B·C·D부터 순서대로 다 쓰면 어떻게 될까요?
**39번째 차에서 보낼 공장이 없습니다.** 타설이 끊깁니다.
가까운 곳을 먼저 비우면 후반에 먼 공장만 남는데, 그 공장들의 시간당 출하 능력을 합쳐도
6분에 한 대를 못 맞추기 때문입니다."

🗣 "이게 저희가 최적화를 쓴 이유입니다. 단순히 가까운 순서로는 안 됩니다."

> 💡 **「39번째에서 끊긴다」** 이 숫자를 꼭 말하세요. 발표의 핵심 문장입니다.

🗣 "그런데 '안 됩니다'로 끝내지 않습니다. **지금 조건에서 몇 ㎥까지 되는지** 계산해 줍니다."
